Claves Groq
-----------
Principal:
  GROQ_API_KEY=...

Credenciales adicionales autorizadas para continuidad operativa:
  GROQ_API_KEY_2=...
  GROQ_API_KEY_3=...
  GROQ_API_KEY_4=...

También puede usarse:
  GROQ_API_KEYS=claveA,claveB,claveC

El router elimina duplicados automáticamente.

Cuándo cambia de credencial
---------------------------
- 401/403: puede probar la siguiente credencial.
- Error de red: puede probar la siguiente.
- Error 5xx de Groq: puede probar la siguiente.
- 404/modelo retirado: cambia de MODELO dentro de Groq.
- 429/rate limit/cuota: NO cambia de credencial para eludir el límite; devuelve un error y respeta Groq.
